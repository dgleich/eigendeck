# Community forks

Eigendeck aims to be deeply customizable — the way Emacs is — so it fits *your*
presentation workflow. The customization surface isn't fully settled yet, so for
now the best way to tailor Eigendeck is to **maintain your own fork**.

Rather than merging a pull request for every individual tweak (which would pull
the core in too many directions at once), we keep a list of community forks here
so people can find one that matches how they work and contribute to it directly.
It also helps us see which customizations are popular enough to fold back into
core.

## Add your fork

Open a pull request editing the table below. Keep it to one row:

- **Fork** — a link to the repo.
- **Maintainer** — your name/handle.
- **What's different** — one line on what it changes or who it's for.
- **Based on** — the Eigendeck version/commit it tracks (so people can gauge how
  current it is).

Listing is light-touch: a fork here is community-maintained and **not** endorsed,
reviewed, or supported by the core project. Use at your own discretion.
