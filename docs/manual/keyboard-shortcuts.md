# Keyboard shortcuts

Eigendeck follows Mac conventions. On Windows and Linux, use **Ctrl** wherever
this list says **⌘**.

## Files and projects

| Shortcut | Action |
|---|---|
| ⌘N | New project |
| ⌘O | Open project |
| ⌘S | Save |
| ⌘⇧S | Save As… |
| ⌘⇧E | Export to HTML |
| ⌘⇧P | Export printable HTML |
| ⌘, | Settings |
| ⌘Q | Quit |

## Slides

| Shortcut | Action |
|---|---|
| ⌘⇧N | New slide |
| ⌘D | Duplicate (slide, or the selected element) |
| ↑ / ↓ | Previous / next slide (when nothing on the canvas is selected) |

## Editing elements

| Shortcut | Action |
|---|---|
| Arrow keys | Nudge the selected element 1px |
| ⇧ + Arrow | Nudge 10px |
| ⌘] / ⌘[ | Bring forward / send backward |
| ⌘⇧] / ⌘⇧[ | Bring to front / send to back |
| ⌘C | Copy the selected element |
| ⌘D | Duplicate the selected element |
| Delete / Backspace | Delete the selected element |
| Esc | Deselect (back to the slide) |
| ⌘Z / ⌘⇧Z | Undo / redo |

## Text formatting (while editing text)

| Shortcut | Action |
|---|---|
| ⌘B | Bold |
| ⌘I | Italic |
| ⌘E | Center |

## View and presenting

| Shortcut | Action |
|---|---|
| ⌘I | Toggle the Inspector |
| ⌘⇧H | Toggle edit History |
| F5 | Present |
| ⌘⌥S | Toggle speaker notes |
| ⌘⇧F | Hide window chrome |
| ⌘⇧D | Debug console |
