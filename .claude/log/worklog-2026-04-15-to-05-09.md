## Print / PDF Export (May 5-8)

### Export Printable HTML (Cmd+Shift+P)
- Vector text + demo screenshots (hybrid approach)
- Physical units: `@page { size: letter landscape; margin: 0 }`
- Slides at `11in × 6.1875in` with `margin-top: 1.15625in` centering
- All positions in inches, font sizes in points
- `-webkit-print-color-adjust: exact` for backgrounds
- Demo screenshots captured via `modern-screenshot` (foreignObject)
- `pdf-capturing` CSS class hides editor chrome during capture
- Only flips through slides that have demos

### Export to PDF (Screenshots)
- Direct `.pdf` file output, no browser needed
- Captures each slide as JPEG, embeds in PDF via `buildPdf()`
- Minimal PDF generator in TypeScript (no dependencies)

### Print layout journey
- Tried: CSS transform scale, viewport units, absolute positioning
- All failed in Safari's print engine
- Solution: physical units (inches/points), no transforms
- Research: Safari doesn't support `@page { size }`, `margin: 0` suppresses headers/footers
