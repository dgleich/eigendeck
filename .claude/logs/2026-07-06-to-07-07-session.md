## Shipped to `main` (branch `feat/csp-baseline`, fast-forward merged + pushed)

**Demo network security (the bulk of the work).**
- **Manifest gate**: a demo is offline by default; it declares hosts+purpose in a
  `<script type="application/eigendeck-manifest+json">` block. Declared ≠ granted —
  the CSP is scoped to exactly those hosts. `src/lib/demoManifest.ts`,
  `demoMount.ts` (`demoNet`), `demoBridge.ts` (`netBlockMeta`).
- **"No internet means no internet"**: the per-demo CSP is `default-src 'none'` +
  re-open only inline scripts/styles + declared hosts, so remote `<script src>` /
  `<link>` are gated too (not just fetch). WebRTC + WebTransport neutered.
- **Three toggles**: global master (Settings→Security), per-deck block, and
  **per-demo** allow/deny (trust ledger `blockedDemos`). Security window Internet
  tab lists each demo's hosts+purpose (`demoNetReport.ts`). Fail-CLOSED default.
- **"Overridden" motif** (`src/lib/overriddenStyle.ts`): a control overridden by a
  higher setting renders greyed+struck+dimmed. Used in the security panel AND the
  inspector watch/auto-reload toggles.

**Security review + eval fixes (all real, all fixed):**
- CSP injection via unsanitized manifest host → `isValidManifestHost` (strict
  hostname/origin, ReDoS length cap, 32-host cap).
- Trusting a deck wiped the per-deck/per-demo internet block → `createTrusted`/
  `trust` now preserve it.

- `assetProtocol` was `enable:true` / `allow:["**/*"]` (read-any-file) but unused →

**Storage column-order corruption (pre-existing bug, 659e476, 2026-05-27).**
Positional `INSERT INTO elements VALUES(...)` assumed fresh column order, but on
decks whose `asset_id` was `ALTER`-appended (any deck created before 2026-05-27),
asset-backed elements (demo/notebook/image) landed with `asset_id=NULL` +
corrupt `valid_from` → vanished on reload. Fixed: **all INSERTs name their
columns**. Added a regression test (migrated-order table) + a `schema_compat` CI
guard + `every_insert_names_its_columns` source scan. `user's Math-Test.eigendeck`
had the botched graph-explorer demo reverted (backup kept).

**23 CDN demos migrated.** Shipped decks (incl. `welcome.eigendeck`) had demos
loading D3/topojson from a CDN with no manifest → blanked by the gate.

if a demo loads a CDN without one. Verified in the real app (magnetic-powers, 45
