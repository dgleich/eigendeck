## Text Editing (Apr 18-May 4)

### Keyboard shortcuts
- Removed native `CmdOrCtrl+I` accelerator (macOS intercepted before JS)
- Fixed `[contenteditable="true"]` check (was matching `contenteditable="false"`)
- Fixed blanket `stopPropagation()` in text onKeyDown (only stop non-Cmd keys)
- Explicit `document.execCommand` for Cmd+B/I/E (Tauri WebKit doesn't handle natively)
- Cmd+E for center text (justifyCenter)

### Toolbar reliability
- Root cause: 4px dead zone in DraggableBox — micro-movements during double-click or toolbar clicks triggered drag
- Toolbar rewritten: `onMouseDown={preventDefault}` prevents blur, `onClick` restores selection
- Selection saved continuously via `selectionchange` listener

### Double-click to edit (#12)
- 4px dead zone before drag activates — closes #12

### Auto-replace (#14)
- Two-stage: `--` → en-dash (–), then `–>` → arrow (→)
- Full set: →, ←, ↔, ⇒, ⇔, — (em-dash)
- Cursor positioning fixed

### Paste behavior
- Cmd+Shift+V: paste as plain text (strips formatting)
- Menu: Edit > "Paste without Formatting"
- Internal paste moved to `paste` event (not keydown) so system clipboard images take priority (#25)
- Paste position: only offset +40 on same slide, paste in place across slides (#41)

### MathJax inline rendering
- Root cause: `data-valign="bottom"` CSS applied `flex-direction: column` to content div, stacking inline math vertically
- Fix: flex on wrapper div, content div stays block layout
- Fixed in editor, PresentMode, presenter, sidebar thumbnails, and HTML export (5 places)

### Display math editing
- `applyMathLineStyles` was too aggressive: `display:flex`, `whiteSpace:nowrap` broke editing between adjacent `$$` blocks
- Fix: only set `minHeight` and `lineHeight` (reserves space without breaking layout)

### Text-align centering bug (May 4)
- WebKit's `justifyCenter` puts `text-align:center` on `<span>` (inline element, ignored by CSS)
- Fix: sanitize innerHTML string before commit — `<span text-align:center>` → `<div>`
- Also fixes broken `</div></span>` nesting

### Center on Slide buttons
- Inspector shows Center H / Center V / Center for single selected elements
- Centers on 1920x1080 canvas

## SQLite Persistence Bugs (Apr 19-May 4)

### Slide order not preserved (#46)
- Subscriber didn't detect reordering (compared metadata, not array position)
- `flushToSqlite` didn't write position
- Added `position` parameter to `db_update_slide`
- Subscriber now compares element ID order

### Z-order not preserved (#50)
- Same pattern: subscriber didn't detect element array reorder
- Added `dirtyZOrder` tracking set
- `flushToSqlite` calls `db_update_z_order` for affected slides
- Added 7 JS tests + 1 Rust round-trip test

### Slide doubling on open (earlier fix verified)
- `sqliteDbPath` set before `setPresentation()` caused subscriber to re-insert everything
- Fix: disable subscriber during load, reset `prevPresentation`

### Sync leak on duplicate (#45)
- `_syncId` preserved from freed sync, could accidentally restore old sync group
- Fix: clear `_syncId`/`_linkId` on duplicate
- Also: `linkId` was reused as new `syncId` — now uses fresh UUID
- 3 test cases added

### Sync badge visibility (#43)
- Badge shown when partner element no longer exists
- Fix: scan all slides to check for partner

### Duplicate slide in group (#40)
- Inserted at `index + 1` instead of after last group member
- Fix: skip to end of group

### verticalAlign not synced (#48)
- Added to sync propagation list in `updateElement`

### Image paste storing data URLs
- Pasted images stored ~2MB base64 data URL in element JSON
- Fix: store relative path, load via blob URL from SQLite
- Patched local-networks.eigendeck: 79MB → 7.1MB (strip history + dedup images)

### Theme changes not detected
- Added `ps.theme !== cs.theme` to subscriber diff
