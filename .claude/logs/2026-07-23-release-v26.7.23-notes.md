# Eigendeck v26.7.23

The **copy & paste** release. Eigendeck now uses a single OS clipboard with a
private Eigendeck flavor (the way Keynote/PowerPoint/Figma do it) instead of a
separate in-app buffer that could drift out of sync. Plus faster demo switching,
a losslessly re-importable HTML export, and a pile of paste-from-anywhere fixes.

## ✨ Highlights

### Copy & paste, redesigned
- **One clipboard.** The old app-local clipboard buffer is gone. Copy writes an
  Eigendeck private flavor onto the OS clipboard; paste reads it first, then
  falls back through image → SVG → PDF → HTML → text. No more stale pastes, no
  more "⌘V duplicated the wrong slide". Design doc: `docs/copy-and-paste.md`.
- **Paste text onto a slide** — plain or styled text pasted onto the canvas
  becomes a real text element, with pasted colors normalized so an Eigendeck copy
  no longer arrives black-on-black on a dark theme (#161).
- **Paste as…** — a new chooser (Edit menu and canvas right-click) to pick which
  clipboard representation to paste: Image, SVG, PDF, HTML element, Text, or
  **Simple Image** (rasterize the clipboard HTML on demand). Rasterizing is now
  an explicit choice rather than a silent default.
- **⌘D duplicates a selected slide** too, clipboard-free; **⌘V of a copied slide**
  inserts *that* slide, not a copy of the one you're standing on.
- **Caret vs. canvas** is decided by focus and the selection anchor, not just the
  event target — fixes the double-paste where text landed both at the caret *and*
  as a new element.
- Removed **Paste without Formatting** (⌘⇧V + its Edit menu item) — superseded by
  Paste as….

### Paste from other apps
- **Google Sheets / web tables** paste using our own crisp HTML→PNG render instead
  of the low-res bitmap the browser also puts on the clipboard.
- **Google Slides images** paste correctly (#158).
- **HTML paste no longer hangs ~60s** when the copied markup references remote
  images, CSS, or webfonts — the capture path is now network-free and time-boxed.
  Text plus a remote image now pastes as editable text (315 ms, was ~60 s).
- **Linux image/screenshot paste** fixed (#94).
- Styled text from a text app no longer hijacks a copy as a PDF *image* (#161).

### Present mode
- **Nav keys work after you've clicked into a demo** — Space/←/→ once again advance
  the deck when a sandboxed demo iframe has keyboard focus (#155). (Caveat: an
  `html` element marked `interactive` renders as a fully-locked, script-less
  iframe, so a focused native control inside it still swallows those keys.)

### Export & import
- **HTML export is losslessly re-importable** — single-store export carrying real
  asset bytes, with round-trip guards for every element type and a combinatorial
  style matrix.
- **Import from HTML** decodes via a UTF-8-safe shared codec (#164).
- **PDF/print** re-captures notebook previews that were stale after a theme change
  (#140).

### Performance
- Faster **demo switching**: the iframe src is seeded synchronously from the blob
  cache on re-mount, the rAF pump is woken by an explicit poke instead of a 100 ms
  idle nap, deck `@font-face` is only embedded into demos that actually name a
  deck font, and embedded fonts are **WOFF2** (~40% the size of TTF).
- New structured multi-deck benchmark suite (editor + present mode) with per-version
  baselines, so regressions like the one above get caught. See `docs/perf-report.md`.

### macOS
- **Document icon** — `.eigendeck` now declares an exported UTI
  (`dev.eigendeck.presentation`) and binds the doc icon to it (#151).
- **App icon** enlarged inside the squircle (#52).
- **View → Developer Tools** works in release builds; all other debug tooling is
  now compiled *out* of release.

## 🐛 Fixes & polish
- Editor shows a **cut-off indicator** when a text box is too small for its
  content — outside the box, constant on-screen size (#95).
- **Link picker** shows build-adjusted slide numbers and the offset from the link
  origin (#88).
- Editor-inserted `&nbsp;` is normalized to breakable spaces so text wraps (#159).
- Link-badge cluster aligns with the delete button on text elements.
- Dragging a non-demo `.html` file onto a slide falls back to a raw HTML element (#137).
- Demo toolbar button hidden by default (power-user; re-addable).
- Showcase: intro callouts sit behind the demo (#163); embedded WOFF2 fonts are
  subset too.

## 🧪 Testing & docs
- Clipboard interop corpus built from **real macOS pasteboard type lists**
  (Word/Docs/Slides/Sheets/Keynote/Numbers/browsers/TextEdit/VS Code), plus
  copy/paste round-trip and style-normalization matrices (43 cases).
- New e2e probes on the real WebKit rig: caret double-paste, text-overflow badge,
  context menu for every element type (#136), present-mode visual capture (#134),
  import-from-HTML through the seam (#164).
- `docs/SPEC.md` reconciled with the element model and presets; `docs/ELEMENT-CHECKLIST.md`
  now requires HTML round-trip verification for new element types.
- New docs: `copy-and-paste.md`, `clipboard-formats.md`, `clipboard-paste-research.md`,
  `perf-report.md`.
