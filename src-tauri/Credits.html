Created by David Gleich

Build presentations with embedded interactive HTML demos and LaTeX math.

Open source

Tauri, React, Zustand, Vite, CodeMirror, MathJax, highlight.js, marked, modern-screenshot, SQLite (rusqlite), and PDFium.

Font families — SIL OFL 1.1, each with a matching math font

PT Sans, Lato, Libertinus, Libertinus Sans, Computer Modern Sans, Noto Sans, Source Sans 3, Source Code Pro, Shantell Sans, Computer Modern Concrete.

Monospace / code fonts — SIL OFL 1.1

Fira Code, IBM Plex Mono, Inconsolata, JetBrains Mono, PT Mono, Computer Modern Typewriter.

Math is set with MathJax using custom math-font packs matched to these fonts.
