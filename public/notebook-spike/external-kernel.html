Notebook spike — external Jupyter kernel

Tests whether eigendeck can talk to a user-run jupyter server via REST + WebSocket. Any kernel (Python, Julia, R, ...) works.
How to start a kernel-friendly Jupyter server

In a terminal on the same machine:

jupyter server --no-browser --port=8888 \
  --IdentityProvider.token='spike-token' \
  --ServerApp.allow_origin='*' \
  --ServerApp.disable_check_xsrf=True

Why each flag: --no-browser = don't open a tab; token = simple auth; allow_origin='*' = let this page (different origin) connect; disable_check_xsrf = let cross-origin POSTs through. Token + CORS lockdown will be tightened before this goes into the real app.
